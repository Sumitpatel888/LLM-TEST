# ⚔️ BLEACH — Soul Requiem

A cinematic, premium-quality **BLEACH-inspired frontend experience** built entirely with **HTML, CSS, and JavaScript**.

The project explores the visual atmosphere of Soul Society through a dark monochromatic interface, sharp red accents, dramatic typography, layered imagery, subtle grain, motion, and interactive storytelling.

## ✨ Features
- 🎬 Full-screen cinematic hero section
- ⚔️ Shinigami & Zanpakutō-inspired visual identity
- 🩸 Black, white & red art direction
- 🌑 Layered atmospheric backgrounds
- ✦ Smooth scrolling and reveal animations
- 🌀 Parallax depth effects
- 👤 Character showcase
- 📜 Featured BLEACH arcs
- ⚔️ Zanpakutō section
- 🏯 Soul Society / faction-inspired sections
- 💬 Memorable quote treatment
- 🖼️ Anime-inspired visual archive
- 🖱️ Interactive hover effects
- 📱 Fully responsive design
- ♿ Reduced-motion support
- ⚡ Lightweight — no frameworks or build tools required

## 🛠️ Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- CSS animations & transitions
- Responsive CSS
- Web fonts / external visual references

No installation is required.
Simply open `index.html` in a modern web browser.

## 🎨 Design Direction
The interface is inspired by the visual language of **BLEACH**:
- Soul Society
- Shinigami
- Zanpakutō
- Hollows
- Bankai
- Japanese calligraphic influences
- High-contrast monochrome compositions
- Sharp red highlights
- Cinematic anime promotional artwork

The goal is to create an experience that feels like an **art-directed anime promotional website**, rather than a conventional template.
